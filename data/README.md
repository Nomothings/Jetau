# Episode data

Jeτ uses a shared step format across the six tasks. Each JSONL line is an
episode with an ordered sequence of observations, candidate actions, a target
action, and feedback:

```json
{"task":"maze","episode_id":"maze-train-0001","split":"train","steps":[{"t":1,"obs":"...","candidates":{"up":"...","right":"..."},"action":"right","event":"..."}]}
```

Each task directory contains `train.jsonl`, `dev.jsonl`, and `test.jsonl`.
Maze and Snake retain their original grid metadata (`size`, `seed`, and
`epsilon`) in place of `task`, `episode_id`, and `split`; the step schema is
identical and the loader accepts both forms.
`action` is a key in that step's `candidates` map. The model sees the current
observation and candidate set; the target action supplies step-level
supervision. Actions and feedback are passed to the state writer as the episode
progresses.

| Task | Episode construction | Source |
|---|---|---|
| Maze | Partial 5×5 observation in an 8×8 maze; BFS-guided actions | Generated by `jet/maze_env.py` |
| Snake | Fully visible 8×8 board; safe movement and food collection | Generated by `jet/snake_env.py` |
| Pokémon | Custom 3v3 turn-based simulator and heuristic action teacher | Generated by `jet/pokemon_env.py`; inspired by Pokémon battle mechanics |
| ALFWorld | Expert household trajectories converted to candidate-action episodes | [ALFWorld](https://github.com/alfworld/alfworld) |
| Mind2Web | Annotated web actions converted to element-choice episodes | [Mind2Web](https://github.com/OSU-NLP-Group/Mind2Web) |
| WebShop | Shopping episodes generated with an offline search and reward replica | [WebShop](https://github.com/princeton-nlp/WebShop) |

The included ALFWorld interaction evaluator uses a deterministic PDDL world
model derived from the benchmark data, not the TextWorld game engine. The
WebShop interaction evaluator uses an offline product corpus and search
replica, not the hosted WebShop site. Mind2Web is evaluated at the annotated
element-selection step. These details matter when interpreting the reported
numbers.

The normalized episodes are included for training and step-level evaluation.
Large upstream raw corpora and model weights are not included. To regenerate
decision-task episodes, see `jet/gen_data_alfworld.py`,
`jet/gen_data_mind2web.py`, and `jet/gen_data_webshop.py`; each accepts local
raw-data paths. Upstream data remains subject to its source license and terms.
